# Telegram-бот практик (MVP)

Реализация раздела «БОТ» из `docs/ТЗ.md`: онбординг, опросник (6 разделов),
бесплатные практики, paywall, покупка → интенсивность → расписание,
ежедневные напоминания с кнопками «Сделал / Позже / Пропустить», мягкий
streak, еженедельная сводка, архив `/practices`.

## Стек

- Python 3.11+, [aiogram 3](https://docs.aiogram.dev/) — Telegram Bot API, FSM-диалоги
- SQLAlchemy 2.0 (async) + SQLite (`aiosqlite`) — модель данных из ТЗ
- APScheduler — минутный диспетчер напоминаний, перенос «Позже» через 2 часа,
  30-минутный nudge, еженедельная сводка по понедельникам

## Запуск

```bash
cd bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # впишите BOT_TOKEN от @BotFather
python -m app.main
```

База (`bot.db`) и 6 категорий с практиками из `app/seed_data.py`
создаются автоматически при первом запуске.

## Что реализовано (по разделу «Обязательно в MVP» из ТЗ)

- Онбординг: `/start` → «опишите состояние» (keyword-классификация без LLM,
  как рекомендовано для MVP) или выбор из 6 кнопок → подтверждение раздела
- Бесплатные практики (1–2 на раздел) → апсейл → мок-оплата → вопрос об
  интенсивности → часовой пояс → время → генерация расписания
- Напоминания по расписанию (проверка раз в минуту), кнопки
  «Сделал ✅ / Позже ⏰ / Пропустить», nudge через 30 минут, перенос на
  2 часа при «Позже»
- Мягкий streak: один пропуск не обнуляет прогресс (обнуление только после
  `STREAK_GRACE_MISSES` пропусков подряд, `app/config.py`)
- Еженедельная сводка (streak, X из Y дней)
- Архив `/practices` — все купленные разделы вне расписания
- Мягкая формулировка «не терапия», детект кризисных формулировок в
  свободном тексте → рекомендация обратиться к специалисту
